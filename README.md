# KnowLayer HR Policy Chatbot

KnowLayer is a modular-monolith RAG chatbot. It retrieves relevant chunks from a local Chroma vector database, uses bounded conversational context for follow-up questions, and returns grounded answers with source citations through a Streamlit chat interface. The current `input/` directory contains the Nexora employee handbook; the ingestion and retrieval components are designed to support additional documents.

## Current MVP

- Local document storage in `input/`
- DOCX, TXT, Markdown, and RST ingestion
- Text extraction and chunking with `python-docx` for DOCX files
- Local persistent Chroma database in `.chroma/`
- Sentence-transformer embeddings
- FastAPI chat endpoint at `/api/chat`
- Streamlit chat UI
- Citation rendering with source, section, and evidence text
- Bounded conversational query resolution for follow-up questions
- OpenRouter primary LLM with Groq fallback
- Distance-aware evidence selection and out-of-domain rejection
- Unit, contract, integration, and smoke tests

The final answer is generated by the configured LLM provider using only the selected document evidence. If no sufficiently relevant evidence is retrieved, the API returns an information-not-found response with no citations rather than fabricating an answer.

## Prerequisites

- Windows PowerShell
- Python 3.11 or newer
- At least one supported source document in `input/`
- Internet access on the first run so Python packages and the embedding model can be downloaded
- API keys in a local `.env` file for OpenRouter and Groq generation

No separate Chroma server is needed. The MVP uses `chromadb.PersistentClient` and stores the database locally in `.chroma/`.

## Setup

Open PowerShell in the project root:

```powershell
cd "C:\path\to\Company_Bot"
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Edit `.env` and provide valid `OPENROUTER_API_KEY` and `GROQ_API_KEY` values. Do not commit `.env` or expose either key. `.env.example` contains placeholders only.

Index the documents before the first chat run:

```powershell
.\.venv\Scripts\python.exe scripts\ingest_documents.py
```

The embedding model may take time to download on the first run.

## Start the Product Automatically

After setup and ingestion, run:

```powershell
.\setup.ps1
```

`setup.ps1` starts the already-created virtual-environment processes in two PowerShell windows. It does not create the environment, install dependencies, or ingest documents.

The services are available at:

- FastAPI: `http://127.0.0.1:8000`
- Health check: `http://127.0.0.1:8000/health`
- Streamlit: `http://127.0.0.1:8501`

Keep both service windows open. Open the Streamlit URL and ask a question. The assistant displays only the evidence selected by the backend.

## Re-ingest Documents

Document ingestion is not part of application startup. The existing Chroma index is reused. If source documents change, run ingestion manually:

```powershell
.\.venv\Scripts\python.exe scripts\ingest_documents.py
```

For a clean rebuild, stop the applications, remove `.chroma/`, and ingest again:

```powershell
Remove-Item -Recurse -Force .chroma
.\.venv\Scripts\python.exe scripts\ingest_documents.py
```

## Request and Answer Flow

```text
User
  -> Streamlit chat or POST /api/chat
  -> QueryOrchestrator
  -> bounded conversation query resolution when needed
  -> Chroma candidate retrieval with Sentence Transformer embeddings
  -> cosine-distance relevance filtering and evidence selection
  -> compact context assembly
  -> OpenRouter primary LLM
  -> Groq fallback when the primary provider fails
  -> grounded answer and citations from the same selected evidence
```

Standalone questions go directly to retrieval. Dependent follow-ups may be rewritten into a standalone retrieval query using the most recent bounded conversation messages. The original user question is retained for final answer generation.

## RAG and Evidence Selection

`ChromaVectorStore` persists embeddings and metadata in `.chroma/`. The embedding model is configured by `EMBEDDING_MODEL` and defaults to `sentence-transformers/all-MiniLM-L6-v2`. Chroma uses cosine distance: lower distance means a closer match. Each result preserves its text, metadata, and raw distance.

`RetrievalService` retrieves candidates, including candidates for explicit multi-part query pieces, and then selects final evidence. Selection:

- applies the configurable absolute distance threshold;
- can accept a top-ranked candidate slightly above that threshold only when it is within the configured relaxation, has a meaningful distance gap over the next candidate, and has generic lexical grounding with the query;
- removes duplicate or highly redundant chunks;
- covers distinct query parts where strong evidence exists; and
- limits both the final evidence count and assembled context size.

Only the selected evidence is sent to the LLM, converted into citations, and displayed by Streamlit. Weak or out-of-domain retrieval produces no citations.

## Conversation Context

`SessionMemoryService` keeps only the most recent six messages by default. `ConversationQueryResolver` detects likely dependent questions using generic conversational references or continuation phrasing. When needed, it asks the configured LLM to produce only a standalone retrieval query from that bounded history. The rewrite is used only for retrieval; the final LLM receives the original user question and selected document context. If rewriting fails, retrieval falls back to the original question.

This is bounded conversational context, not long-term memory or a user profile store.

## LLM Providers and Grounding

`LLMProvider` defines the provider-independent generation interface. `FallbackLLMProvider` calls OpenRouter first and calls Groq with the same messages if the primary provider raises `LLMProviderError`. The provider clients use model names from `LLM_MODEL` and `GROQ_MODEL`.

The current confirmed Groq fallback model is `openai/gpt-oss-20b`. API keys belong only in the local `.env` file. Never commit them. `.env.example` contains placeholders only.

The final generation prompt restricts answers to retrieved document context. When selected evidence is empty, the orchestrator returns an information-not-found response and an empty citation list without calling an answer-generation provider.

## Citations and Provenance

`ProvenanceService` builds citations from the metadata attached to selected Chroma results, including source and section, together with the evidence text. The API serializes these citations and Streamlit renders the returned list without selecting additional chunks.

## Configuration

The application reads `.env` through [app/core/settings.py](app/core/settings.py). The current settings and defaults are:

```text
DOCUMENTS_DIR=<project>/input
COLLECTION_NAME=hr_policy_docs
EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2
RAG_DISTANCE_THRESHOLD=0.50
RAG_DISTANCE_RELAXATION=0.05
RAG_MIN_DISTANCE_GAP=0.10
RAG_CANDIDATE_COUNT=5
RAG_MAX_EVIDENCE=3
RAG_MAX_CONTEXT_CHARS=12000
OPENROUTER_API_KEY=
GROQ_API_KEY=
LLM_MODEL=openrouter/anthropic/claude-3.5-sonnet
GROQ_MODEL=llama-3.1-8b-instant
```

The `.env.example` template currently uses placeholders for the API keys and sets `GROQ_MODEL=openai/gpt-oss-20b`. Environment values override the code defaults. The application’s local `.env` should use the confirmed available Groq model.

## Troubleshooting

**PowerShell blocks the script:** run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned`.

**The UI says connection refused:** start FastAPI first and confirm `http://127.0.0.1:8000/health` returns `{"status":"ok"}`.

**The collection is empty:** confirm supported documents are in `input/`, then run the ingestion command again.

**The first run is slow:** Sentence Transformers downloads its embedding model once and may take several minutes.

**The primary provider fails:** the fallback provider is attempted automatically. Confirm `GROQ_API_KEY` is configured and `GROQ_MODEL` names an available Groq model.
